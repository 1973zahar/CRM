# Arms CRM MVP

Самодостатній прототип CRM для продажу цивільної зброї та аксесуарів. Відкрийте `index.html` у браузері або запустіть `mock-api.ps1` для локального статичного сервера з тестовими API endpoints. Дані інтерфейсу зберігаються локально в `localStorage`, експорт доступний кнопкою `⇩` у верхній панелі.

## Що реалізовано

- Каталог товарів із двома типами: `Зброя` із серійним обліком та `Звичайні товари` з кількісним обліком.
- Обов'язковий контроль серійного номера, ЄРЗ, номера дозволу та дати дозволу під час продажу зброї.
- Роздрібний, сайтовий, маркетплейсний та B2B канали продажу.
- Накладні, оплати, касові зміни, дебіторка за менеджерами та прив'язка платежів до документів.
- Мультивалютність: UAH, USD, EUR, курс дня, конвертація залишків у валюту обліку.
- Відповідальне зберігання та B2B кабінети з інвентаризацією і звітом проплат.
- Інтеграційний екран для Rozetka, Prom, Epicentr, Allo, банків та BAS/BAF.
- Ролі з блокуванням редагування документів після закриття дня.

## Наступний production-етап

1. Backend: PostgreSQL + API service, аудит змін, файлове сховище фото товарів.
2. Авторизація: ролі співробітників, окремий B2B tenant/cabinet, журнал дій.
3. Інтеграції: реальні конектори Rozetka/Prom/Epicentr/Allo, банки, BAS/BAF.
4. Документообіг: рахунок, видаткова, ТТН, акти відповідального зберігання, повернення.
5. Compliance: окрема перевірка ЄРЗ, дозвільні документи, неможливість змін після проведення без спеціальної ролі.

## Файли

- `index.html` — оболонка застосунку.
- `styles.css` — інтерфейс CRM.
- `app.js` — бізнес-логіка, seed-дані, перевірки, localStorage.
- `mock-api.ps1` — локальний mock API та статичний сервер без npm/Node.
- `api-contract.md` — контракт майбутнього backend/API.

## Локальний API запуск

```powershell
powershell -ExecutionPolicy Bypass -File .\mock-api.ps1 -Port 8787
```

Після запуску:

- `http://127.0.0.1:8787/index.html`
- `http://127.0.0.1:8787/api/health`
- `http://127.0.0.1:8787/api/products`
- `http://127.0.0.1:8787/api/integrations`
